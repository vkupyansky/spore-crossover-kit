# Spore CrossOver Kit

Скрипт запуска, настройки графики и небольшие диагностические инструменты, сохранённые из настройки Steam Spore: Galactic Adventures на Mac с Apple silicon.

**[Скачать исходники v0.1.0](https://github.com/vkupyansky/spore-crossover-kit/releases/download/v0.1.0/spore-crossover-kit-0.1.0-source.tar.gz)** · [Выпуск и SHA256SUMS](https://github.com/vkupyansky/spore-crossover-kit/releases/tag/v0.1.0)

## Возможности

| Компонент | Назначение |
| --- | --- |
| [Скрипт запуска](launch-spore.command) | Исправляет путь к творениям, проверяет работу Steam и вход в аккаунт, явно задаёт каталог данных игры. |
| [Фрагмент настроек графики](config/graphics.properties) | Сохраняет максимальное качество, оконный режим и отдельные изменения ограничения кадров. |
| [Проверка пакетов](tools/check_packages.py) | Показывает одинаковые и различающиеся ресурсы, которые пересекаются в пакетах модов DBPF. |
| [Патч SporeKit](patches/sporekit-watchdog/README.md) | Сохраняет исправление диагностического чтения имён модулей и Windows-тесты. Дополнительный материал для разработчиков. |

## Подготовка и запуск

Нужны macOS, CrossOver и отдельно установленные Steam-версии **Spore и Galactic Adventures** в одной Windows-бутылке. Исходная среда: CrossOver 26.3, Apple silicon, Steam GA 3.1.0.29. Файлы игры, CrossOver, моды и данные аккаунтов не включены.

1. Распакуйте архив исходников. Установите обе игры в стандартную библиотеку Steam внутри бутылки: `C:\Program Files (x86)\Steam\steamapps\common\spore`.
2. Откройте Steam в этой бутылке, войдите в аккаунт и дождитесь библиотеки.
3. Откройте терминал в каталоге проекта и выполните:

```sh
./launch-spore.command --bottle SporeCoop
```

Имя бутылки по умолчанию: `SporeCoop`. Это историческое имя: скрипт не устанавливает и не использует кооператив. Для другого имени передайте `--bottle NAME`. По умолчанию CrossOver находится в `/Applications/CrossOver.app`; другое расположение задаётся через `--crossover /path/to/CrossOver.app`. Поддерживается стандартный каталог бутылок `~/Library/Application Support/CrossOver/Bottles` и стандартное подключение Documents.

Исправление пути к творениям без запуска Spore:

```sh
./launch-spore.command --bottle SporeCoop --prepare-only
```

Команда устанавливает 32-битное значение реестра Spore `PlayerDir` в `My Spore Creations` и создаёт эту папку в Documents. Язык игры сохраняется. Обычный запуск проверяет живой процесс Steam в выбранной бутылке и передаёт `SteamAppId=24720`, `-dataDir:...\Data`, `-w` и `-r:1920x1080`. Скрипт не запускает Steam и не включает подробные логи Wine.

## Графика и дополнительные моды

При закрытой игре примените [рецепт настройки графики](docs/graphics.md). Он объединяет десять ключей настроек и меняет интервал кадров на 16 мс в обоих каталогах конфигурации игры. Это даёт теоретический предел 62,5 FPS.

[Состав использованной сборки модов](docs/mods.md) и [зафиксированные ссылки и SHA-256](metadata/mods.json) сохранены как дополнительная справка. Автоматической установки нет. Основная настройка не использует SporeKit и SporeCoop.

## Проверка пакетов

Нужен Python 3.10 или новее, дополнительные пакеты не требуются:

```sh
python3 tools/check_packages.py /path/to/DataEP1
```

Можно передавать файлы пакетов или каталоги. Каталоги читаются на один уровень, без рекурсии. Коды выхода: `0` означает отсутствие разных пересечений, `1` означает пересечение различающихся сохранённых ресурсов, `2` означает некорректные данные или неподдерживаемый формат. Поддерживается Spore DBPF 3.0 с индексом 0.3. RefPack сравнивается в сохранённом виде, без распаковки. Пересечения могут быть намеренными; это не заключение о совместимости модов.

## Проверки

На macOS с Python 3.10+ и консольной утилитой `make`:

```sh
make check
```

Команда проверяет синтаксис zsh и запускает изолированные тесты скрипта запуска и чтения пакетов. Тесты запуска используют поддельный CrossOver и никогда не запускают игру. У архивного патча есть [отдельная процедура Windows-теста](patches/sporekit-watchdog/README.md#test).

## Ограничения

- Последняя правка с явным каталогом данных прошла проверки аргументов и обработки ошибок, но последующий реальный запуск игры не проверен. Нельзя считать ошибку 1004 и последующие ошибки инициализации модов универсально исправленными.
- Скрипт обходит кнопку запуска Steam: русский установочный скрипт может вернуть недопустимое имя папки творений. Подписанные установочные скрипты Steam не меняются. Связанный случай описан [в исходном проекте](https://github.com/WoodyWizard/SporeCoop/issues/190).
- Full HD задаётся как желаемый размер окна. SporeBorderless может подогнать его под монитор; фактическое разрешение на Retina не измерялось. FPS также не измерялся.
- Ранее оконный режим 1600 x 1000 восстанавливался после сворачивания, а эксклюзивный полный экран зависал. Более позднее сочетание Full HD и Borderless полностью не проверено.
- Статические проверки и тесты не доказывают стабильность всей сборки модов. Патч watchdog хранится отдельно и не требуется основному скрипту запуска.
